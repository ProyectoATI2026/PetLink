# Guía de Estilo y Contribución

## Estándares de Código
- **Formateo:** Todo el código debe pasar por el linter/formateador configurado en el proyecto antes de enviar un PR.
- **Indentación:** Usar 4 espacios.
- **Nombres:**
  * Variables y funciones: `camelCase` o `snake_case` (según el lenguaje principal).
  * Clases y tipos: `PascalCase`.
  * Constantes: `UPPER_SNAKE_CASE`.

## Commits
Sigue el formato de [Conventional Commits](https://www.conventionalcommits.org/):
- `feat: agregar sistema de autenticación`
- `fix: corregir fuga de memoria en el parser`
